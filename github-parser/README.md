# 🔥 GitHub Parser — Auto Config Grabber

Автоматический парсер конфигов с GitHub.

## 🚀 Что делает
- Парсит весь GitHub каждый час
- Находит vless, trojan, hysteria2, ss, vmess
- Проверяет работоспособность
- Переименовывает по шаблону
- Обновляет файл working_configs.txt

## 📁 Результат
`working_configs.txt` — готовые рабочие конфиги.
